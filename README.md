## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **portfólio profissional pessoal**. O projeto foi planejado e desenvolvido com o objetivo de apresentar minha identidade como Desenvolvedor Web, exibir meus principais projetos práticos, destacar minhas competências técnicas e facilitar o contato profissional.

O design prioriza uma experiência fluida, limpa e moderna, aplicando conceitos avançados de estilização e arquitetura front-end.

---

## ✨ Principais Funcionalidades & Destaques

- **Layout 100% Responsivo:** Abordagem *Mobile First* com adaptação fluida de tamanhos utilizando `clamp()` e media queries estratégicas.
- **Seção Hero Interativa:** Apresentação de alto impacto visual com tipografia destacada e chamadas para ação diretas.
- **Seção de Stack Tecnológica:** Organização clara das ferramentas e linguagens divididas entre *FrontEnd*, *BackEnd* e *Ferramentas*.
- **Vitrine de Projetos:** Cards dinâmicos destacando os trabalhos realizados (como o *Nexos Lab* e o *Criador de Senhas*), incluindo links diretos para os repositórios e versões online.
- **Depoimentos e Contato Direto:** Seção dedicada a feedbacks simulados e canais de contato rápidos (E-mail estruturado via link direto, LinkedIn e GitHub).

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web essenciais e boas práticas de desenvolvimento:

* **HTML5:** Estruturação semântica e acessível.
* **CSS3 / SCSS:** Estilização modular avançada, variáveis customizadas (`:root`), Flexbox e CSS Grid.
* **JavaScript (ES6+):** Comportamentos dinâmicos e navegação fluida (`scroll-behavior: smooth`).
* **Google Fonts:** Tipografia utilizando as fontes *Inter* e *IBM Plex Mono*.
